# «Пелюстка» — квіткова майстерня

Односторінковий навчальний сайт українською мовою. Створений на HTML, CSS і JavaScript без фреймворків, тому його можна опублікувати через GitHub Pages.

## Що вже працює

- Адаптивна головна сторінка з каталогом, відгуками, журналом, контактами й FAQ.
- Пошук букетів і фільтри за категоріями.
- Кошик із кількістю товарів і підсумком у гривнях. Вміст зберігається у браузері.
- Квітковий помічник із відповідями на типові запитання та рекомендаціями за нагодою й бюджетом.
- Історія чату зберігається у sessionStorage в межах вкладки; демонстраційна статистика тем — локально у браузері.
- Форма контакту показує підтвердження на сторінці. Вона не надсилає дані на сервер.

## Публікація через GitHub Pages

1. Створи новий репозиторій на GitHub.
2. Завантаж у нього index.html, styles.css, script.js і цей README.md.
3. У налаштуваннях репозиторію відкрий Pages.
4. У джерелі публікації вибери гілку main і папку / (root), потім збережи.
5. Дочекайся завершення публікації — GitHub покаже адресу сайту в розділі Pages.

## Як змінити вміст

- Назви, описи, ціни та фото товарів лежать у масиві products у файлі script.js.
- Основні тексти, контакти, FAQ і статті розміщені в index.html.
- Кольори й адаптивне оформлення — у блоці :root файлу styles.css.

## Важливо про демо-функції

Кошик і статистика працюють лише в браузері відвідувача. Чат відповідає за набором правил і FAQ, він не підключений до GPT. Для GPT, реального оформлення замовлень, серверної аналітики та надсилання контактної форми потрібен окремий бекенд. Не додавай секретний ключ GPT API у JavaScript-файли, які публікуються у відкритому репозиторії.
